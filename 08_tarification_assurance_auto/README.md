# Projet : Analyse et Tarification en Assurance Auto

## Description
Ce dossier contient le projet réalisé par **GADO Giovanni** et **AWOUTO Samson** dans le cadre du cursus ISE3. 

Il s'agit d'une étude en finance et actuariat portant sur le domaine de l'assurance automobile. Le projet inclut les codes sources en R (via RMarkdown) pour l'analyse des données et la modélisation, ainsi que le rapport final détaillé.

## Application Interactive
Dans le cadre de ce projet, une application Shiny a été développée pour présenter les résultats de façon interactive.

🔗 **Découvrir l'application :** [Lys Assurance Auto](https://mesapplications.shinyapps.io/lys-assurance-auto/)

## Contenu du Dossier
- `Code_Tarification_Assurance_Auto.Rmd` : Code source RMarkdown contenant les analyses, la modélisation et la génération du rapport.
- `Rapport_Tarification_Assurance_Auto.pdf` : Rapport final de l'étude.
- `Data/` : Répertoire contenant les jeux de données utilisés pour l'analyse.
- `Sorties/` : Répertoire contenant les différents outputs générés par le code.
